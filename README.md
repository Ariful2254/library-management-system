# Library Management System

A desktop-based application designed to efficiently manage and automate daily library operations, such as tracking books, managing members, and handling book issues/returns.

# Features
1. Book Management: Add, update, view, and delete book records.
2. Member Management: Register new members/students and maintain their profiles.
3. Issue & Return: Track borrowed books, return dates, and manage due timelines.
4. Search Functionality: Easily search for books and members by ID or name.

# Technologies Used
-Language: Java
-IDE: NetBeans
-Database: MySQL (Change this if you used another database)
